# TaskFlow

A dark, mobile-friendly PMO task tracker MVP.

## Run locally

1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Current MVP

- Master Tracker dashboard
- Eight seeded PMO tasks
- Main Tasks and To-Do Lists
- End/reopen actions
- Automatic progress and completion status
- Search and status filtering
- Responsive mobile layout
